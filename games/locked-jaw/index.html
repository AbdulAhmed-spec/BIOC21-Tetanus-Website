About this game & the science

This is a fictional case and a simplified learning model, not a diagnostic tool. Alex is already receiving medical care. The activity asks students to explain a mechanism rather than make treatment decisions.

Tetanus bacteria can grow in a low-oxygen wound and release toxin. The toxin travels along nerves to the central nervous system, where it prevents release of inhibitory chemical messengers. The model simplifies this to a blocked “brake” signal and excessive motor output. Switching conditions compares models; it does not represent removing toxin from a patient.

Learn more: CDC: Tetanus (opens in a new tab). Progress stays in this page’s memory and resets on refresh. No scores or personal information are sent anywhere.

This game includes one case, three clues, one signal comparison and one evidence puzzle. No drawing recognition, treatment simulation, or timer.
